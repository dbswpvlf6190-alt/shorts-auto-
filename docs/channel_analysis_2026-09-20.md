# 채널 성장 분석 (2026-09-20)

데이터: YouTube Analytics API(영상별·일별·유입·시청자·시청유지곡선), 영상 메타데이터 247편, 인스타그램 인사이트 34릴스. 틱톡은 접근 불가.
스크립트: `scripts/analytics/` (pull_analytics.py, analyze.py, redo_windows.py). 로컬 `output/_analysis/`에서 실행.

## ⚠️ 분석 함정 (반드시 읽을 것)
1. **YouTube Analytics의 일자 경계는 한국시간이 아니라 태평양시.** 한국 오전(1~10시) 업로드 영상은 한국 날짜로 창을 잡으면 **업로드 당일이 통째로 빠짐**. 그런데 쇼츠 조회수의 약 99%가 업로드 후 2~3일 안에 몰림. 창 시작을 `공개시각(UTC) - 1일`로 잡을 것. 이 실수로 처음엔 "자동화 영상 조회수가 1/3"이라는 **틀린 결론**이 나왔다가 정정됨.
2. `per_video` 리포트는 조회수 상위 ~200편까지만 반환 → 하위 영상은 `filters=video==ID`로 개별 조회해야 함(안 하면 저조한 영상이 빠져 성적이 부풀려짐).
3. `subscribersGained`는 트래픽소스 리포트에서 지원 안 됨.
4. 영상 `publishedAt`은 비공개로 올렸다가 공개 전환한 시각으로 갱신됨.

## 확정된 사실 (근거 강함)
- 채널: 구독 203, 총조회 177,471. 구독 증가: 자동화 이전(6/1~8/14 약 11주) 주당 3~25명(합 약 118) → 자동화 후(8/15~9/20) **37일간 4명**.
- **영상당 도달은 자동화 초기까지 동일**: 업로드 후 15일 조회 중앙값 OLD 877 vs AUTO 838 (p=0.69, n=60/20). 히트(800회↑) 비율 62% vs 50%.
- **품질·전환이 붕괴**: 평균시청비율 중앙값 80% vs 54% (p=0.0001) / 스와이프 안 한 비율 37.4% vs 27.4% / 좋아요 12.3 vs 4.1 (1000뷰당) / **구독 1.65 vs 0.07 (1000뷰당, 약 23배 차이)**. 구독 1명 이상 얻은 영상 비율 68% vs 5%.
- 시청 유지(시점별 중앙값): 10초 시점 OLD 93% vs AUTO 65%, 6→8초 구간에서 급락. 이 격차의 대부분이 첫 10초 안에서 생김(이후 감소 속도는 비슷).
- **자동화 기간 내부 악화(7일 창, 올바른 창)**: 8/15~8/29 조회 중앙 893·시청비율 59%·스와이프안함 25% → 8/30~9/8 287·44%·29% → 9/9~9/12 128·36%·15%(길이 44s→50s→58s, 음성 edge-tts→복제음성, 9/9 방송속보 훅). 여러 변경이 동시에 겹쳐 개별 원인 분리는 불가.
- 시청자: 45세 이상 92~96%(55~64세 35%, 65세 이상 28~41%), 한국 99.7%, 모바일 94%, 남성 55~61%. 자동화 이전과 구성 거의 동일 → 시청자층 변화는 원인 아님.
- 유입: 쇼츠 피드 95%, 검색 3.2%. **기존 구독자의 시청은 전체의 0.24%**(48/20,033).
- 길이 vs 평균시청비율: 스피어만 -0.26(OLD n=205), -0.33(AUTO n=39). 길수록 이탈.
- 인스타(@daily.factlab): 팔로워 1, 릴스 34개, 조회 중앙값 70, 좋아요 합 9, 댓글 0, 저장 0.

## 검증했는데 영향 없음/불명 (시간 낭비 금지)
- 제목 특성(숫자, "~인데", 의문형, 따옴표형, 30자↑): 모두 p>0.3.
- 업로드 요일, 업로드 시각(창 오류 수정 후 p=0.45), 주제(세금/경매/전세 등 중앙값 유사).
- **가설 기각**: "훅이 본문 첫 문장을 반복해서 이탈" — 겹침 비율(중앙 50%)은 실제로 높지만 영상별 성적과 무관(스피어만 -0.04, p=0.89, n=17).

## 관찰(통계 아닌 정성 근거, n=2)
잘 전환된 옛 영상(8/3 "세제 이렇게 바뀝니다"→구독+6, 6/24 전세가율→+6) 썸네일: **AI 생성 실사풍 이미지/영상(주제 관련 장면) + 부드러운 "~해요" 체 큰 자막 + 30~40초.** 우리 영상: 남색/골드 통계 카드 + "~합니다" 체 + 46~66초.

## 실험 설계 메모
영상 단위 평균시청비율 SD≈25~32p → 팀당 10편으로는 36p 차이도 겨우 검출(현재 격차 26p보다 큼) → **영상 중앙값 비교로는 검정력 부족.** 판정은 조회 단위로 합산한 비율(스와이프안함 비율, 10초 시점 유지율, 1000뷰당 좋아요/구독)로 할 것(수천 뷰 단위라 검정력 충분).
