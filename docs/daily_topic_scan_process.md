# 매일 소재 발굴 프로세스

이 문서는 "오늘 쓸만한 소재 뽑아줘" 요청이 오면(또는 스케줄로 자동 실행되면) 따르는 절차.

## 절차
1. WebSearch로 아래 카테고리를 순환하며 최신 뉴스 확인 (검색어에 항상 현재 연월 포함)
   - 세금/정책: 종부세, 양도세, 취득세, 세제개편
   - 경매 시장: 낙찰가율, 유찰, 경매 진행건수
   - 전월세: 전세가율, 전세사기, 깡통전세
   - 대출/금리: DSR, LTV, 기준금리
2. 뉴스성 있는 것(수치 변화, 정책 발표, 논란) 위주로 2~4개 추림 — 단순 정보 나열성 기사는 제외
3. 각 소재에 [script_template.md](script_template.md)의 4가지 훅 패턴 중 3개를 적용해 훅 문장 버전 작성 (반전형/숫자형/이유형 우선)
4. `input/topics_YYYYMMDD.md`에 저장 (형식은 기존 파일 참고)
5. 사용자에게 리스트 제시 → 하나 골라서 대본 작성 → `make_short.py`로 완성본 제작

## 주의
- 같은 소재를 반복하지 않도록 과거 topics_*.md 파일 확인
- 세금/법 관련 수치는 출처 URL을 같이 남겨서 나중에 팩트체크 가능하게 함
