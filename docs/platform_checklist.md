# 플랫폼별 배포 체크리스트

## 공통 (자동 파이프라인이 이미 처리)
- 해상도 1080x1920 (9:16) — 세 플랫폼 다 동일 규격
- 자막은 하단에서 340px, 좌우 90px 여백 확보 — 유튜브 구독버튼/틱톡·릴스 우측 아이콘 줄과 안 겹치게

## 유튜브 쇼츠
- 제목에 실제 궁금증 유발 문구 + 해시태그 2~3개(너무 많이 넣지 않기 — 상위권 영상 보면 해시태그 적은 쪽도 잘 됨)
- 첫 화면(썸네일 프레임)이 곧 썸네일이 되니, 인트로 이미지가 눈에 띄는지 확인

## 틱톡
- 우측 세로 아이콘 줄(좋아요/댓글/공유/사운드)이 화면 우측 ~150px 차지 — 자막이 거기 안 걸리는지 최종 확인
- 커버(썸네일) 별도 지정 가능하니 업로드 시 챙기기

## 인스타그램 릴스
- 하단 캡션+사용자명 영역이 꽤 넓음(약 200~250px) — 지금 마진(340px)이면 충분히 안전
- 커버 프레임 별도 지정 가능

## 업로드 전 공통 확인
- [ ] 자막 오탈자 확인 (TTS 자동생성이라 가끔 틀림)
- [ ] 세금/법 관련 수치 출처 재확인
- [ ] 완성본 실제로 재생해서 자막 타이밍/UI 겹침 눈으로 체크
- [ ] 게시는 항상 본인이 최종 확인 후 직접 업로드 (자동 게시 안 함)
