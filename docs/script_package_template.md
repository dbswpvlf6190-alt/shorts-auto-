# 숏츠 콘텐츠 패키지 포맷 (사용자 실전 포맷, 2026-08-15 확립)

대본 요청 시 항상 이 구조 전체를 채워서 출력한다. 하나의 소재 = 이 패키지 하나.

```
# YYYY.MM.DD 숏츠 대본

**소재:** (한 줄 요약)
**기준일:** YYYY.MM.DD

---

## 유튜브 훅 (단어 분리, 0~3초)
(짧은 문장을 단어/구 단위로 줄바꿈 — 유튜브는 한 단어씩 순차 등장 연출)

---

## 틱톡 훅 (한 번에 등장, 0~1.5초 — 단어분리 X)
**(임팩트 문장 전체를 한 번에)**
> 연출: 빨강/검정 고대비, 확대 효과, 텍스트 전체 동시 등장

---

## 오늘 영상 제목
(유튜브 훅과 같은 문장, 해시태그 없이)

---

## 틱톡 캡션 (meta.json의 tiktok_caption 필드로도 저장 — 파일명에 그대로 들어감)
(임팩트 문장 + 이모지 + 댓글유도 + 해시태그. 큐 처리 시 이 텍스트가 틱톡 파일명에 그대로 박혀서, 업로드할 때 파일명 복붙만 하면 되게 함)

## TTS 대본 (문장별)
(문장마다 줄바꿈. script_template.md의 4가지 훅 패턴 + A/B 규칙 적용.
보통 5~7문장, 마지막은 댓글 유도 질문으로 마무리)

---

## 유튜브 제목
(제목 + 해시태그 2개)

---

## 유튜브 설명란
(TTS 대본을 풀어쓴 2~3문단 + 채널 소개 한 줄 + 해시태그 8~10개)

---

## 틱톡 캡션
(짧은 임팩트 문장 + 이모지 + 댓글유도 문구 + 해시태그 4~5개, 유튜브와 다른 톤)
```

## 주의사항
- 유튜브 훅과 틱톡 훅은 같은 내용이어도 연출 지시가 다름 (유튜브=단어별 순차, 틱톡=한번에+고대비+확대)
- 해시태그는 유튜브 설명란(많이) vs 유튜브 제목(2개만) vs 틱톡 캡션(적게, 이모지 섞음) — 위치마다 다르게
- TTS 대본은 `make_short.py --script` 입력으로 그대로 사용 가능 (문장 구분 줄바꿈은 무시되고 한 덩어리로 읽힘)
