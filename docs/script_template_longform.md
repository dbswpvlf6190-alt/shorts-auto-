## 대본 규칙
- **분량:** 해요체로 8~10분. 공백 포함 약 3,500~4,500자이고 `rate` 기본값은 "+10%"다.
- **구조:** 인트로(훅 → 결론 요약 → 기준일 고지) → 본론 장 3~5개 → 정리(체크리스트) → 공유·댓글 질문 → 다음 영상 예고.
- **챕터:** 유튜브 챕터 조건 때문에 장은 3개 이상이어야 한다. 장 제목이 `chapters.txt`에 들어간다.
- **장면 길이:** 한 장면 voice는 1~4문장이다. 화면은 문장보다 느리게 바뀌어도 되고, 자막이 음성을 따라간다.
- **출처:** 장마다 `source`로 단다(화면 우상단에 표시). 장면 하나만 출처가 다르면 그 장면에 `source`를 따로 준다.
  - **확인 안 된 수치·실무 관행은 쓰지 않는다.** 확인한 근거는 `fact_check`에 적는다.
- **기준일:** 정책은 바뀌므로 인트로에 "○○년 ○월 기준"을 말하고 설명에도 적는다. 국회 통과 전인 개편안은 반드시 "통과 전"이라고 밝힌다.
- **예시 금액:** `number` 장면 `note`에 "(예시 금액 · 가정)"을 넣는다.
- **voice의 단어 수가 타이밍 기준이다.** 공백으로 나눈 단어 수가 그대로 쓰이므로 문장을 그대로 적는다. 숫자는 "82.5퍼센트", "20퍼센트포인트"처럼 읽는 대로 쓴다.

## meta.json
```
{ "format": "long", "rate": "+10%", "fact_check": "...",
  "youtube_title", "youtube_description", "tags", "privacy",
  "thumbnail": { "lines": ["{노랑}", "흰색 [빨강]"], "badge": "2026 막차", "image_prompt": "photorealistic ..." },
  "chapters": [ { "title": "① ...", "tag": "화면 상단 띠 문구", "source": "출처: ...", "scenes": [ ... ] } ] }
```
공통 필드는 `voice`(읽을 문장, 필수)와 선택 `source`다.
화면 글자 마크업: `{주황/노랑 강조}`, `[빨강 경고]`, `\n` 줄바꿈.

| kind | 필수 | 선택 | 화면 |
|---|---|---|---|
| **art (주력)** | `image_prompt`(영어, 장면 묘사만 — 스타일은 빌더가 붙임) | `title`·`en`(바뀔 때만, 없으면 앞 장면 제목 이어받음), `big`(왼쪽 큰 숫자) | 영화풍 AI 그림(FLUX.2 klein 16:9) + 천천히 확대·축소 + 오른쪽 위 제목·영어 부제. **전체의 80% 이상**, 장면당 1~2문장(7~10초) |
| title | `title` | `number`, `sub` | 짙은 남색 장 제목 카드 (장 시작·예고) |
| cards | `cards:[{title}]` 2~4개 | `heading`, 카드별 `label`, `body`, `color`(red/orange/green/navy) | 흰 카드가 하나씩 나타남 |
| number | `amount`(숫자) | `unit`, `label`, `note`, `color`, `heading` | 큰 숫자 카운트업 |
| checklist | `items:[{text}]` | `right`(오른쪽 날짜), `mark:"x"`(안 되는 것), `color` | 줄이 하나씩 체크됨 |
| compare | `left`, `right`: `{title, lines[], color}` | `heading` | 좌우 비교 |
| timeline | `points:[{date, label}]` | `active`, `color` | 날짜 연표 |
| photo | `caption` | `image_prompt` | 사진(Cloudflare) + 큰 자막. **전체의 1/4 이하** |
| quote | `text` | `cite`, `heading` | 강조 상자(주의·법령 문구) |

단계형 장면(cards·checklist·compare·timeline)은 장면 앞 70% 구간에 하나씩 드러난다. 시각을 직접 정하려면 `reveal_at:[초,…]`, 한 번에 다 보이려면 `reveal:"all"`을 쓴다.

  - ① **지금 터진 숫자 + 역설**로 시작한다: "사상 최대 흑자인데 40년 만의 최저", "전문가 예측과 정반대", "손해 같은데 큰손은 담는다".
  - ② **돈의 이정표**를 다룬다: 10억, 시작점.
  - ③ **같은 돈 A vs B 비교**를 한다: 같은 3,000만 원, 같은 S&P500.
  - ④ **날짜가 박힌 기회**를 다룬다: 5월 22일 판매 시작.
- **조회수 하위 공통점:**
  - 막연한 비법형: "비밀 ETF 포트폴리오", "가장 완벽한 매도 타이밍", "무섭게 부자되는".
  - 가입 방법 안내형: ISA 가입방법(2,749회).
  - 긴 나열 제목.
  - 10월 최근작은 2~7만 회로 하락세다.
- **썸네일:**
  - 화면 아래쪽 1/3에 **큰 글자 2줄**(흰색 + 노랑/초록/빨강)을 넣는다.
  - 숫자나 날짜를 꼭 넣는다(1560원 > 1370원, 3000만원, 10억).
  - "vs" 비교와 '이것' 같은 궁금증 단어를 쓴다.
  - 배경은 그림 한 장면이다. 흰 동그라미 마스코트가 있지만 우리는 사용자 의견에 따라 쓰지 않는다.
- **설명란 반복 요소:**
  - 첫 줄은 역설·숫자 훅이다.
  - ━━━ 구분선과 📌 다루는 내용(·목록)을 쓴다.
  - **"반대로 봐야 할 N가지"** 항목을 넣는다.
  - 채널 신조 문장을 넣는다: "이 채널은 맞히는 법이 아니라 안 당하는 법을 다룹니다."
  - 댓글 질문은 양자택일이다: "바닥이라고 보시나요, 아직 멀었다고 보시나요?"
  - **다음 영상을 예고한다:** "다음 항해는 ~입니다".
  - 📊 주요 출처, ⚠️, 서명 "보물은 찾는 사람한테만 옵니다 ⚓", 해시태그 10~30개.
- **공개 시각(KST):** 19시 12편, 20시 10편, 17시 8편, 21시 6편이다. 저녁 19~20시가 중심이다.

### 대본 2편 교차 분석 (시작점 86만 · 10억 69만, 2026-10-29)
- **0:31 구독 부탁:** 두 편 모두 정확히 0:31에 넣는다. 훅은 시청자 장면이나 지인 이야기("제 지인분이 40대에 10억을 만들었는데 '애매하다'고")로 시작하고, "오늘 이 영상을 보시면 ○○이 완전히 바뀌실 겁니다"라고 약속한다.
- **형식은 두 가지다:**
  - (A) 질문형 이야기: 시작점. 큰 비유 1개 + 떡밥이다.
  - (B) **N가지 목록형:** 10억. 장마다 "첫 번째 …", "여섯 번째 …"라고 **번호를 말로 알린다**. 목록형이면 장 번호를 말해도 된다.
- **한 항목 안의 순서:**
  1. 공신력 있는 통계로 시작한다(KB 부자보고서 47만 6천 명, 0.92%).
  2. 생활 장면으로 그린다(PB 라운지, 커피 한 잔).
  3. 실제 의미를 짚는다.
  4. 숫자로 비교한다(월 211만 vs 352만, 10년이면 1억 6천).
  5. "물론 ~"으로 단서를 단다.
  6. **외울 한 문장으로 닫는다.**
- **외울 한 문장 예시:**
  - "10억을 은행에 맡겼더니 신입 사원이 됩니다"
  - "세금을 모르면 10억이 9억이 됩니다"
  - "아무것도 안 한다는 것 자체가 이미 선택입니다"
  - "10억은 게임이 끝나는 지점이 아니라 규칙이 바뀌는 지점입니다"
- **연구 인용:** 연구 1~2개를 이야기처럼 인용한다(2013 사이언스지 사탕수수 농부 인지능력 +13, 카너먼 손실회피 2배).
- **감정 장:** 돈이 아니라 마음을 다룬다("싫은 걸 거절할 수 있는 힘", "새로운 종류의 외로움"). 댓글과 공감이 나오는 구간이다.
- **중간 떡밥:** "이 현실에 대해서는 뒤에서 더 자세히 다루겠습니다"
- **끝맺음:**
  1. 한 문장으로 정리한다.
  2. "좋아요 한번 눌러 주세요, **알고리즘에 큰 힘**이 됩니다"라고 말한다.
  3. 댓글로 본인 상황을 묻는다.
  4. **다음 영상을 구체적으로 예고한다**("포트폴리오 구성 전략은 다음 영상에서").
