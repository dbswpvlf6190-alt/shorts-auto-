# 주간 성과 리뷰 프로세스

**주기: 매주 토요일** (2026-08-22 확정) — 이날 사용자와 함께 유튜브·인스타그램 실적을 발표하고, 다음 주 개선점을 논의/반영한다.

## 절차 (주 1회, 토요일)
1. 브라우저로 `https://www.youtube.com/@daily.factlab/shorts` 접속, "인기순" 탭 클릭
2. 상위 10개 + 이번 주 새로 올린 영상들의 조회수를 `output/channel_snapshots/YYYY-MM-DD.md`로 저장 (지난 스냅샷 형식 그대로)
3. 직전 스냅샷과 비교:
   - 이번 주 올린 영상이 채널 평균(상위권 기준)을 넘었는지
   - 어떤 훅 유형(반전/숫자/이유/실시간이슈)이 이번 주에 더 잘 나왔는지
4. 패턴이 바뀌었으면 `script_template.md`의 "검증된 4가지 훅 패턴" 섹션 업데이트
5. 결과를 사용자에게 짧게 요약 보고

## 파일 위치
- 스냅샷: `output/channel_snapshots/`
- 템플릿: `script_template.md`
