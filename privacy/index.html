1. 이 도구가 하는 일

'도장찍기전에 업로더'는 채널 운영자 본인이 만든 영상을 운영자 본인의 틱톡 계정 임시 저장함(받은 편지함)으로 보내는 개인용 도구예요. 다른 사람은 쓰지 않아요.

2. 받는 정보

틱톡 로그인 허용 시 틱톡이 주는 접근 토큰, 계정 식별값(open_id), 허용한 권한 목록만 받아요. 이름·연락처·팔로워·영상 시청 기록 같은 정보는 받지 않아요.

3. 쓰는 곳

운영자 본인 계정으로 영상을 보내는 데만 써요. 광고, 분석, 판매, 제3자 제공에 쓰지 않아요.

4. 보관과 삭제

토큰은 운영자 개인 컴퓨터에만 저장되고 서버에 올리지 않아요. 틱톡 앱의 설정 → 보안 → 앱 권한에서 언제든 연결을 끊을 수 있고, 끊으면 토큰은 더 이상 쓸 수 없어요. 로컬 파일도 함께 지워요.

5. 문의
